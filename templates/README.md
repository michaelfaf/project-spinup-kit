# templates/

The files the implementing AI copies (and adapts) into the user's workspace as `(PROJECT TEMPLATE)/`. Which ones get installed depends on DP-2 and DP-5 in `IMPLEMENT.md`.

| Template | Install when |
|---|---|
| `PROJECT-README.md` → `README.md` | always |
| `PROJECT-STATUS.md` → `STATUS.md` | always |
| `LOG.md` → `History/LOG.md` | always |
| `LESSONS.md` → `History/LESSONS.md` | DP-5 = B or C |
| `NEXT-CHAT.md` (created at retire, not pre-created) | DP-4 = A |
