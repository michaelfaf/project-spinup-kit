# templates/

The files the implementing AI copies (and adapts) into the user's workspace as `(PROJECT TEMPLATE)/`. Which ones get installed depends on DP-4 and DP-5 in `IMPLEMENT.md`; DP-2 decides how much of the set each new project starts with.

| Template | Install when |
|---|---|
| `PROJECT-README.md` → `README.md` | always |
| `PROJECT-STATUS.md` → `STATUS.md` | always |
| `LOG.md` → `History/LOG.md` | always (under DP-2 light, the file is created at first retire) |
| `LESSONS.md` → `History/LESSONS.md` | DP-5 = B or C |
| `NEXT-CHAT.md` (created at retire, not pre-created) | DP-4 = A |
| `DECISION-BRIEF.md` (one numbered copy per researched decision, not pre-created) | DP-5 = C |
